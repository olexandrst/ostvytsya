# Оствиця — мобільний квест (Android)

Автономний Flutter-додаток для Android: керування персонажами, промптами й
голосами, запуск квестів — без жодного сервера. Додаток говорить напряму з
Gemini Live API та OpenAI Realtime API, використовуючи ключі, які користувач
сам вводить у налаштуваннях (жодного логіна). Кожен квест триває від початку
до кінця, а по завершенню (перемога чи тайм-аут) той самий персонаж
запускається знову — і так по колу, доки квест не зупинять вручну. Додаток
працює й з вимкненим екраном (основний режим): foreground-сервіс + wake lock
не дають системі приспати процес.

## Архітектура (коротко)

- `lib/models/character.dart` — модель персонажа (назва, провайдер
  OpenAI/Google, голос, швидкість мовлення, вільний системний промпт, таємне
  слово).
- `lib/services/character_store.dart` — персонажі зберігаються як окремі
  JSON-файли в теці документів застосунку; три типові персонажі
  (Домовичок/Водяник/Повітруля) копіюються з assets при першому запуску.
- `lib/services/settings_store.dart` — ключі Gemini/OpenAI у захищеному
  сховищі пристрою (`flutter_secure_storage`).
- `lib/quest/openai_transport.dart`, `lib/quest/gemini_transport.dart` —
  пряме WebSocket-з'єднання з OpenAI Realtime і Gemini Live API (без
  офіційного Dart SDK для Gemini — протокол реалізовано вручну на основі
  вихідного коду `google-genai`).
- `lib/quest/audio_pipeline.dart` — мікрофон і відтворення голосу через
  `flutter_sound`; половинний дуплекс (мікрофон вимкнено, поки персонаж
  говорить).
- `lib/quest/quest_controller.dart` — оркестрація одного квесту (виявлення
  таємного слова, тиша, ліміт тривалості) і нескінченний цикл перезапуску.
- `android/.../QuestForegroundService.kt` — нативний foreground-сервіс +
  `PARTIAL_WAKE_LOCK`, щоб квест не зупинявся з вимкненим екраном.

## Збірка через GitHub Actions

У репозиторії є workflow `.github/workflows/mobile-build.yml`, який збирає
release APK і додає його як артефакт збірки.

**Як запустити білд:**

1. Відкрий вкладку **Actions** репозиторію на GitHub.
2. У списку зліва обери **«Mobile — збірка Android APK»**.
3. Натисни **Run workflow** (кнопка справа), обери гілку — і запусти.
4. Зачекай, поки збірка позеленіє (кілька хвилин).
5. Відкрий завершений запуск → розділ **Artifacts** внизу сторінки →
   завантаж **ostvytsya-quest-release-apk** (zip з `app-release.apk` всередині).
6. Перекинь `app-release.apk` на телефон (напр. через USB, хмару чи посилання
   в Telegram) і встанови його (потрібно дозволити встановлення з
   «невідомих джерел» в Android — система запитає сама при спробі
   встановлення).

Workflow також запускається автоматично при пуші чи pull request, що
торкається теки `mobile/`.

## Локальна збірка (якщо є Android SDK)

```bash
cd mobile
flutter pub get
flutter build apk --release
# результат: build/app/outputs/flutter-apk/app-release.apk
```

## Перше налаштування в додатку

1. Відкрий **Налаштування** (іконка шестерні на головному екрані) і встав
   ключ Gemini API (aistudio.google.com/apikey) та/або OpenAI API
   (platform.openai.com/api-keys) — залежно від того, яких персонажів
   плануєш використовувати.
2. На головному екрані вже є три типові персонажі. Натисни на картку, щоб
   почати квест, або через меню (три крапки) — редагувати, клонувати чи
   видалити.
3. Під час першого запуску квесту додаток попросить дозвіл на мікрофон і
   запропонує дозволити роботу без обмежень батареї (щоб квест не зупинявся
   з вимкненим екраном) — обидва варто дозволити.
4. Кнопка **«Зупинити квест»** на екрані квесту зупиняє цикл перезапуску.
