# Локальні голосові оголошення

`restart_notice.mp3` — оголошення після перезапуску квесту з веб-панелі:

> УВАГА! Інтерактивного персонажа перезапущено. Щоб розпочати новий квест —
> промовте кодове слово.

Файл у репозиторії **не лежить** (у середовищі збірки немає доступу до
синтезаторів мовлення) — його треба згенерувати або записати один раз і
покласти сюди; далі він потрапляє в APK. Поки файла немає, застосунок
озвучує текст системним синтезатором Android (потрібен український голос,
Google TTS його має).

Згенерувати на комп'ютері з інтернетом:

```bash
pip install gTTS
python scripts/make_restart_notice.py      # → mobile/assets/audio/restart_notice.mp3
```

Або записати живим голосом і зберегти як MP3 (моно, 44,1 кГц достатньо) під
цим самим ім'ям. Текст оголошення в коді — `RestartNotice.text`
(`mobile/lib/quest/restart_notice.dart`); якщо змінюєш формулювання —
перезапиши й файл.
